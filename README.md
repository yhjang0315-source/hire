# 커리어 사다리 (가칭)

**2026 고용24 국민참여 AI 고용서비스 발굴 온라인 해커톤** 참가 프로젝트

신입 구직자의 관심 직종·전공·경력·지원/불합격 이력을 분석해 **탈락 원인을 진단**하고,
목표 직장까지 가는 **단계별 실제 공고**와 **판단 근거·이후 계획**을 함께 제시하는 AI 커리어 동행 서비스.

## 공모전 개요

| 항목 | 내용 |
|---|---|
| 주최 | 고용노동부 · 한국고용정보원 |
| 접수 | 2026.9.21 ~ **10.13(화)** — 1차 기획안 PDF 10쪽 이내 |
| 일정 | 10월 1차 심사(20팀) → 10~11월 온라인 MVP 개발(2주) → 11월 2차 기능심사 → 11~12월 본선·시상 |
| 요구 | AI를 접목한 고용24 서비스 MVP, 고용24 OpenAPI·EIS·ELDS·공공데이터포털 활용 |
| 참가 | 개인 |

## 핵심 기능

1. **탈락 원인 진단** — 자격 격차형 / 서류 표현형 / 조직 적합형으로 구분
2. **두 갈래 추천**
   - 사다리 트랙: 목표 공고 · 경력 발판 · 역량 키우기 · 즉시 적합 단계별 공고
   - 방향 전환 트랙: 눈을 낮추지 않고 서류·면접·회사 선택 방향 개선
3. **추천 카드** — 설득 한마디 + 판단 근거 + 12개월 계획
