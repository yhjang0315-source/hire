## 2. 확보 방안

1. **공개 데이터(1~6)**: 공공데이터포털·고용24 Open API 인증키를 발급받아 호출. 직업정보(약 500개 직업)·훈련과정은 사전 수집·캐시하고, 공고는 실시간 조회(호출 한도 대응).
2. **비공개 데이터(7~8)**: 고용24 입사지원 이력·직업심리검사 결과는 공개되지 않으므로 실제와 유사한 형태의 **모의데이터**로 대체. 실제 개인정보는 포함하지 않음.
3. **확장 시**: 고용24 입사지원 이력, 직업심리검사(직업선호도·직업가치관) 결과를 본인 동의 하에 연동.
