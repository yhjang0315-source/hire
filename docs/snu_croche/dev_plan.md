## 3. 사전 준비 (10.1~10.13)

1. **개발 환경**
   1. Node.js LTS, Expo CLI, VS Code, AI 코딩 도구 설치
   2. 휴대폰에 Expo Go 설치, 연습용 빈 프로젝트로 실행 확인
   3. 연습 프로젝트에서 `expo-notifications`(로컬 알림), `expo-document-picker`, `expo-image-picker` 사용법 익히기 — 본 프로젝트 코드로 가져오지 않는다
2. **시연 데이터 (가상)**
   1. 과제 안내 PDF 3개: 보고서(경영학원론), 코딩(자료구조 과제 3, 제출 시각 누락 → 되묻기 유도), 녹강 공지(통계학 7주차)
   2. 시간표 이미지 1장, 알바 일정
   3. 미리형·몰아형 사용자 프로필 2개와 1주 타이머 기록
3. **디자인 자산**: 캐릭터 4표정(첨부 PDF의 SVG) PNG로 내보내기, 색 토큰
4. **발표 자료 틀**: 6장 목차대로 빈 슬라이드 준비
5. **기타**: 재학(휴학) 증명 자료, 휴대폰 화면 미러링 테스트
6. **OT에서 확인할 질문**
   1. Croche SDK를 React Native에서 바로 부를 수 있는가, 아니면 서버가 필요한가
   2. PDF·이미지 파일을 모델에 직접 넣을 수 있는가 (표준 Tool에 파일 읽기가 있는가)
   3. 구조화 출력(JSON 스키마)을 지원하는가
   4. Memory에 사용자별 값을 저장·조회하는 방법, Tool 등록 방법
   5. 크레딧 100달러 기준 모델별 사용량 확인 방법

### 4.3 데이터 모델

```ts
type TaskType = "report" | "problem" | "coding" | "slides" | "team" | "exam" | "lecture";

interface Task {
  id: string; title: string; course: string; type: TaskType;
  dueAt: string;                 // 녹강은 수강 인정 기간 종료 시각
  amount?: string;               // "A4 5쪽", "문제 3개", "75분"
  lecture?: { openAt: string; videoMin: number; attendRule?: string };
  estimateH: number;             // AI 추정
  needH: number;                 // estimateH × 보정 배율 (녹강은 videoMin ÷ 배속 + 정리)
  steps: string[];               // AI가 쪼갠 단계
  firstStep: string;             // 첫 15분 할 일
  submitFormat?: string;
  questions?: { field: string; ask: string; suggested?: string }[];  // 되묻기
  weight?: number;               // 성적 반영 비중(선택)
}

interface FixedEvent { day: 0|1|2|3|4|5|6; start: string; end: string; label: string }

interface StyleProfile {
  mode: "early" | "cram";        // 미리형 / 몰아형
  startDaysBefore: number;       // 평균 시작 시점
  multiplier: Record<TaskType, number>;
  focusMin: number;              // 집중 지속 시간
  preferred: ("morning"|"afternoon"|"evening"|"night")[];
  wake: string; sleep: string;
}

interface Block { id: string; taskId: string; start: string; end: string;
  status: "planned" | "done" | "missed" | "moved" }

interface TimerLog { taskId: string; start: string; end: string }
```

### 4.4 스케줄러 (`scheduler.ts`)

`schedule(tasks, fixed, style, doneLogs, now) → { blocks, overload }`

1. 가용 슬롯 = 오늘~마지막 마감까지 기상~취침 − 고정 일정 − 30분 단위 여유
2. 과제별 남은 시간 = needH − 지금까지 타이머 합계
3. 시작 시점
   - 미리형: 마감 − (남은 시간 ÷ 하루 가용 시간 + 2일)
   - 몰아형: 마감 가까이 채우되, D-2 이전에 첫 블록 1개 강제
4. 우선순위 = 임박도(1 ÷ 남은 일수) × 남은 시간 × (weight ?? 1) 순으로 슬롯 배정
5. 블록 길이 ≤ focusMin, preferred 시간대 슬롯부터
6. 재조정 = `now` 이후로 같은 함수를 다시 실행 (지난 planned 블록은 missed, 새로 배치된 것은 moved)
7. 과부하 = 마감 전 가용 시간 < 남은 시간이면 부족 시간과 선택지 3개 반환

→ 순수 함수라 테스트 케이스(미리형/몰아형/과부하)로 먼저 검증한다.

### 4.5 압박 단계 (`pressure.ts`)

`level(task, blocks, logs, now) → "notice" | 0 | 1 | 2 | 3`

- 진행률 = 타이머 합계 ÷ (now 이전 계획 블록 시간 합계)
- 날짜 구간 = 첫 블록 전 / ~D-3 / D-2~D-1 / 당일
- [service_spec.md 4.5](service_spec.md) 표를 그대로 룩업 테이블로 구현

### 4.6 Croche 호출 (`croche.ts`)

| 함수 | 입력 | 출력 | 모델 | 호출 시점 |
|---|---|---|---|---|
| `extractTasks` | PDF·이미지·텍스트 | `Task[]`(추정 시간·단계·첫 15분·되묻기 포함) | 고성능 | 과제 추가 시 1회 |
