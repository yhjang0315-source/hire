## 1. 전제

1. Croche는 공개 자료를 찾지 못해 **AI 앱 빌더·에이전트 플랫폼**(프롬프트로 화면·로직·AI 기능을 만드는 도구)이라고 가정했다. 공식 자료를 확인하면 4장 'Croche 활용'을 고친다.
2. 개발 기간이 3일이므로 **외부 데이터 1~2종 + LLM**으로 핵심 흐름이 작동해야 한다.
3. 주최가 서울대 창업지원단이므로 **사업화 가능성**이 심사에서 중요하다고 보았다.
4. 고용24 출품작(커리어 사다리)과 겹치지 않는 주제로 골랐다.

## 4. 후보별 요약

### A. 졸업 플래너

1. **문제**: 졸업요건(전공·교양·복수전공·졸업논문)이 흩어져 있어 막학기에 미이수를 발견하는 경우가 생긴다.
2. **핵심 기능**: 성적표 업로드 → 남은 요건 계산 → 목표 졸업 학기에 맞춘 학기별 수강 계획 → 요건 변경 시 알림
3. **사업화**: 개인 무료 + 대학 교학처 대상 상담 보조 도구 판매
4. **Croche 활용**: 성적표·학사요람 PDF 파싱, 요건 계산 로직, 수강 계획 대화형 조정
5. **위험**: 학사요람 해석 오류는 곧 졸업 문제로 이어져 신뢰 부담이 크다.

### B. 팀플 매니저

1. **문제**: 조별과제에서 역할이 흐려지고, 무임승차 여부를 증명하기 어렵다.
2. **핵심 기능**: 회의 기록 요약 → 할 일·담당자 자동 배정 → 마감 알림 → 개인별 기여 기록(동료평가 근거)
3. **사업화**: 학생 무료, 대학 LMS 연동 기관 판매
4. **Croche 활용**: 회의 요약·할 일 추출 에이전트, 알림 자동화
5. **위험**: 노션·슬랙 등 기존 도구 대비 전환 이유가 약하다.

### C. 창업지원사업 코치 (추천)

1. **문제**: 예비창업 학생은 지원사업이 너무 많아 맞는 공고를 찾기 어렵고, 자격 요건을 놓치거나 사업계획서를 심사 기준과 동떨어지게 쓴다.
2. **핵심 기능**
   1. 아이디어·팀 정보 입력 → 공고 매칭(자격 요건 충족 여부 표시)
   2. 선택한 공고 양식(PSST: 문제·해결·성장·팀)에 맞춘 사업계획서 초안
   3. 심사 기준별 자가 점검과 보완 제안
3. **데이터**: 창업진흥원 K-Startup 사업공고 조회 API(공공데이터포털) — 제공 항목은 확인 필요
4. **사업화**: 개인은 지원사업 시즌 단기 구독, 기관은 대학 창업지원단·창업보육센터 라이선스(상담 인력 보조)
5. **Croche 활용**: 공고 검색 → 자격 판단 → 문서 생성 → 점검으로 이어지는 다단계 에이전트 흐름
6. **위험**: 사업계획서를 대신 써 주는 도구로 보이면 심사 공정성 논란이 생길 수 있다 → '초안·점검 코치'로 포지셔닝하고, 최종 작성은 사용자가 하도록 설계한다.
