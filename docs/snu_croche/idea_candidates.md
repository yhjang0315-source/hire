## 2. 전제

1. **Croche**는 H1R AI가 만든 'AI 서비스를 위한 AX Kit'이다. SDK, 개발 예제, 기술 지원을 제공한다. SDK의 세부 기능(모델, 음성, 메모리 등)은 Notion 공지에서 확인이 필요하다(현재 세션에서 접근 불가).
2. **심사 중점**(1문1답)
   1. 사용자의 어떤 문제를 풀고, 실제로 쓸 이유가 분명한가
   2. 핵심 기능이 실제로 동작하고, 자연스럽게 쓸 수 있는가
   3. AI가 필요한 역할을 하며 의미 있는 가치를 주는가
   4. **AI 운영 비용과 제공 가치가 균형을 이루는가**
3. 개발 기간이 3일이고 크레딧이 100달러이므로, 외부 데이터 1~2종 + 호출 수가 적은 AI 흐름이어야 한다.
4. 고용24 출품작(커리어 사다리)과 겹치지 않는 주제로 골랐다.

## 5. 후보별 요약

### A. 졸업 플래너

1. **문제**: 졸업요건(전공·교양·복수전공·졸업논문)이 흩어져 있어 막학기에 미이수를 발견하는 경우가 생긴다.
2. **핵심 기능**: 성적표 업로드 → 남은 요건 계산 → 목표 졸업 학기에 맞춘 학기별 수강 계획 → 요건 변경 시 알림
3. **사업화**: 개인 무료 + 대학 교학처 대상 상담 보조 도구 판매
4. **Croche 활용**: 성적표·학사요람 PDF 읽기, 수강 계획 대화형 조정
5. **위험**: 학사요람 해석 오류는 곧 졸업 문제로 이어져 신뢰 부담이 크다.

### B. 팀플 매니저

1. **문제**: 조별과제에서 역할이 흐려지고, 무임승차 여부를 증명하기 어렵다.
2. **핵심 기능**: 회의 기록 요약 → 할 일·담당자 자동 배정 → 마감 알림 → 개인별 기여 기록(동료평가 근거)
3. **사업화**: 학생 무료, 대학 LMS 연동 기관 판매
4. **Croche 활용**: 회의 요약·할 일 추출 에이전트, 알림 자동화
5. **위험**: 노션·슬랙 등 기존 도구 대비 전환 이유가 약하다.

### C. 창업지원사업 코치 (추천)

1. **문제**: 예비창업 학생은 지원사업이 너무 많아 맞는 공고를 찾기 어렵고, 자격 요건을 놓치거나 사업계획서를 심사 기준과 동떨어지게 쓴다.
2. **핵심 기능**
   1. 아이디어·팀 정보 입력 → 공고 매칭(자격 요건 충족 여부 표시)
   2. 선택한 공고 양식(PSST: 문제·해결·성장·팀)에 맞춘 사업계획서 초안
   3. 심사 기준별 자가 점검과 보완 제안
3. **데이터**: 창업진흥원 K-Startup 사업공고 조회 API(공공데이터포털) — 제공 항목은 확인 필요
4. **사업화**: 개인은 지원사업 시즌 단기 구독, 기관은 대학 창업지원단·창업보육센터 라이선스(상담 인력 보조)
5. **Croche 활용**: 공고 검색 → 자격 판단 → 문서 생성 → 점검으로 이어지는 다단계 AI 흐름
6. **비용 설계**: 공고는 하루 1회 받아 캐시하고, 자격 판단은 규칙으로 먼저 거른 뒤 AI는 후보 공고 몇 건과 섹션 단위 작성에만 쓴다.
7. **위험**: 사업계획서를 대신 써 주는 도구로 보이면 공정성 논란이 생길 수 있다 → '초안·점검 코치'로 포지셔닝하고, 최종 작성은 사용자가 하도록 설계한다.

### D. 유학생 생활 메이트

1. **문제**: 유학생은 은행 계좌 개설, 병원 진료, 집 계약, 출입국 행정처럼 말과 제도를 함께 알아야 하는 상황에서 막힌다.
2. **핵심 기능**: 상황별 캐릭터 롤플레이(은행원·의사·집주인) → 대화 후 표현·제도 피드백 → 실제 문자·서류 사진을 쉬운 말로 풀이
3. **Croche 활용**: 캐릭터 대화, 사진 속 문서 읽기
4. **위험**: 비자·법률 안내가 틀리면 피해가 크다 → 공식 기관 링크로 연결하고 판단은 하지 않는다.

### E. 선수지식 역추적 튜터

1. **문제**: 전공 수업에서 막히는 이유는 대개 앞 단계 개념을 모르기 때문인데, 무엇을 모르는지 스스로 찾기 어렵다.
2. **핵심 기능**: 강의 자료로 개념 지도 생성 → 막힌 문제를 물으면 짧은 확인 질문으로 빠진 개념 진단 → 그 단계부터 설명·연습 문제
3. **Croche 활용**: 자료 요약·개념 추출, 수준 진단 대화
4. **위험**: NotebookLM·ChatGPT와 차별점이 '역추적 진단' 하나라 시연에서 분명히 보여야 한다.

### F. 전세사기 방어 게임

1. **문제**: 첫 집 계약은 대부분 처음이라 등기부등본·선순위 채권 같은 위험 신호를 모른 채 계약한다.
2. **핵심 기능**: 매물 3개 중 하나를 골라 AI 집주인·중개사와 대화 → 서류 확인·질문으로 위험 신호 찾기 → 결과 리포트와 실제 체크리스트
3. **Croche 활용**: 성격이 다른 NPC 연기, 매 판 다른 사기 시나리오 생성
4. **위험**: 3일 안에 게임 재미와 교육 정확성을 둘 다 잡기 어렵다 → 시나리오 3개로 좁힌다.

### G. 장학금 매칭 에이전트

1. **문제**: 장학금은 한국장학재단·지자체·재단·학교에 흩어져 있어, 받을 수 있는데 몰라서 놓친다.
2. **핵심 기능**: 조건 입력 → 자격 충족 장학금 목록과 마감 알림 → 제출 서류 체크리스트 → 자기소개서 점검
3. **데이터**: 공공데이터포털 장학금 관련 데이터(데이터셋명·항목은 확인 필요)
4. **Croche 활용**: 공고 문장에서 자격 조건 추출, 서류·자기소개서 점검
5. **메모**: C와 구조가 같다(공고 → 자격 판단 → 서류 점검). C는 주최(창업지원단) 적합도가, G는 사용자 규모가 강점이다.

### H. 알바 근로 지킴이

1. **문제**: 주휴수당·야간수당 누락을 알아도 계산이 어렵고, 사장님께 말하기 부담스럽다.
2. **핵심 기능**: 계약서·명세서 사진 → 받아야 할 금액 계산 → 차액과 근거 → 정중한 요청 문구와 신고 절차 안내
3. **Croche 활용**: 사진 속 문서 읽기, 요청 문구 생성
4. **위험**: AI의 역할이 작아 보일 수 있다.
