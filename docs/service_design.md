# 커리어 사다리 — 서비스 설계 (v0.1)

> 2026 고용24 국민참여 AI 고용서비스 발굴 온라인 해커톤 제출용 아이디어 설계 문서
> 작성일: 2026-09-29 · 참가 형태: 개인

## 1. 한 줄 정의

신입 구직자의 관심 직종·전공·경력·**지원/불합격 이력**을 분석해 **탈락 원인을 진단**하고,
목표 직장까지 가는 **단계별 실제 공고(회사+직무)** 와 **판단 근거·이후 계획**을 함께 제시하는 AI 커리어 동행 서비스.

## 2. 해결하려는 문제

1. **"경력 있는 신입"의 벽**: 목표 직종은 신입 채용이 적고 경력을 요구한다.
2. **단편적 탐색**: 구직자는 목표 직종 이름(예: "엔지니어")으로만 검색해, 역량·경력을 쌓을 수 있는 인접 공고를 놓친다.
3. **탈락 원인 불명**: 기업은 탈락 사유를 알려주지 않아, 자격 부족인지 표현·적합성 문제인지 모른 채 같은 방식으로 반복 지원한다.
4. **추천만 있고 설명·계획이 없음**: 추천을 받아도 "왜 여기인지", "그다음은 무엇인지"가 없어 받아들이기 어렵다.

## 3. 기존 서비스와 차별점

| 구분 | 고용24 잡케어 | 고용24 취업확률 기반 구직컨설팅 | 사람인 AI 코칭 등 민간 | **커리어 사다리** |
|---|---|---|---|---|
| 핵심 질문 | 나에게 맞는 직업은? | 희망 직종 취업 확률은? | 이 공고에 맞게 서류를 고치려면? | **목표에 닿으려면 지금 어디에, 어떻게 지원해야 하나?** |
| 추천 단위 | 직업(상위 3개) + 유사 공고 | 훈련·자격증·일자리 | 공고·서류 첨삭 | **단계별 실제 공고(목표/발판/역량/즉시)** |
| 부족 역량 해결 | 훈련·자격증 | 훈련·자격증·서류 보완 | 서류 보완 | **일자리로 채우기(발판 공고) + 훈련 보조** |
| 불합격 이력 | 반영 안 함 | 반영 안 함 | 반영 안 함 | **탈락 원인 진단 → 처방 분기** |
| 설명 | 결과 제시 | 확률·보완점 | 첨삭 | **설득 한마디 + 판단 근거 + 12개월 계획** |

## 4. 타깃 사용자

- **주 타깃**: 경력 없는 신입 구직자(청년), 목표 직종 신입 채용이 적어 반복 탈락 중인 사람
- 대표 페르소나
  - **A(자격 격차형)**: 기계공학 졸업, 목표 기계설계, 서류 5회 탈락, 경력 없음
  - **B(조직 적합형)**: 요건은 충족, 서류 통과 4회 / 면접 탈락 4회

## 5. 사용자 입력

| 항목 | 형식 | 필수 | 용도 |
|---|---|---|---|
| 관심·목표 직종(1~3개) | 선택 + 자유입력 | 필수 | 목표 역량 기준 |
| 전공 | 선택 | 필수 | 학과정보 → 관련 직업·역량 보완 |
| 경력(알바·인턴·프로젝트 포함) | 자유 서술 | 선택 | AI가 역량으로 구조화 |
| 자격증 | 선택 | 선택 | 요건 충족도 |
| 지원 이력 | 공고(고용24 공고번호 또는 텍스트) + 결과(서류탈락/면접탈락/합격/대기) | 선택 | 탈락 원인 진단, 중복 추천 제외 |
| 희망 지역·임금·근무형태 | 선택 | 선택 | 조건 필터 |
| 구직 가능 기간 | 선택(1개월/3개월/6개월+) | 선택 | 급할수록 즉시 적합 비중 ↑ |
| 성향 자가진단(10문항) | 5점 척도 | 조직 적합형 진단 시 | 성향–인재상 비교 |

- 지원 이력은 **직접 입력**(MVP). 고용24 입사지원 이력 연동은 확장 계획.

## 6. 처리 흐름

```
입력
 └─▶ ① 역량 구조화 (AI: 경력 서술 → 역량 키워드)
      └─▶ ② 탈락 원인 진단 (규칙)
           ├─ 자격 격차형 ─▶ 트랙 A: 사다리 (단계별 발판 공고)
           ├─ 서류 표현형 ─▶ 트랙 B1: 방향 전환 (서류 개선)
           ├─ 조직 적합형 ─▶ 트랙 B2: 방향 전환 (맞는 회사 유형 + 면접 개선)
           ├─ 혼합형 ─────▶ A + B
           └─ 판단 보류 ──▶ 기본 추천 (지원 3회 이상 시 진단)
      └─▶ ③ 공고 수집·점수 계산 (고용24 채용정보 API)
      └─▶ ④ 추천 카드 생성 (규칙 수치 + AI 문장)
      └─▶ ⑤ 지원 결과 입력 → 재진단 (피드백 루프)
```

## 7. 공고 점수 (모든 기준값은 초기값, 튜닝 필요)

| 점수 | 정의 | 계산 |
|---|---|---|
| **F 현재 적합도** (0~100) | 내 조건이 공고 요구를 얼마나 충족하나 | 필수요건(학력·전공·자격·경력조건) 충족률 × 0.6 + 우대·스킬 키워드 매칭률 × 0.4 |
| **T 목표 기여도** (0~100) | 이 공고 직무가 목표 직업 역량을 얼마나 길러주나 | 공고 직종의 직업정보(능력·지식 중요도) 벡터와 목표 직업 벡터의 코사인 유사도, 공고 본문 추출 역량으로 보정 |
| **C 경력 인정 가능성** (0~100) | 목표 직종 지원 시 '관련 경력'으로 인정될 가능성 | 직업분류 계층 거리: 동일 소분류 100 / 중분류 70 / 대분류 40 / 기타 10 |
| **S 지금 지원 1순위** | 전체 중 지금 지원할 1곳 | w1·F + w2·T + w3·조건적합(지역·임금) + w4·마감임박 − 제외(이미 탈락한 회사·재지원 제한) |

- S 가중치는 진단 결과와 구직 가능 기간에 따라 조정(예: 구직 기간 1개월 → w1 ↑).

## 8. 탈락 원인 진단 규칙

지원 이력 각 건의 F를 계산해 평균(avgF)과 탈락 단계 비율을 본다.

| 조건 | 진단 | 처방 |
|---|---|---|
| 지원 3회 미만 | 판단 보류 | 기본 추천 + "3번 이상 지원하면 진단이 정확해져요" |
| avgF < 60 & 서류탈락 ≥ 60% | **자격 격차형** | 트랙 A 사다리 |
| avgF ≥ 80 & 서류탈락 ≥ 60% | **서류 표현형** | 트랙 B1: 눈 낮추기 X, 서류에서 역량을 보여주는 방식 개선 |
| avgF ≥ 80 & 면접탈락 ≥ 60% | **조직 적합형** | 트랙 B2: 성향–인재상 비교 → 맞는 회사 유형 + 면접 개선 |
| 그 외 | 혼합형 | A + B 병행 |

### 조직 적합형 세부

1. **회사 쪽**: AI가 탈락 공고 본문에서 인재상·조직문화 키워드를 추출해 공통 패턴을 찾는다.
2. **사용자 쪽**: 성향 자가진단 10문항, 5개 축
   - 속도 ↔ 신중 / 주도 ↔ 협력 / 변화 ↔ 안정 / 큰 그림 ↔ 디테일 / 독립 ↔ 팀
3. **비교**: 축별 차이가 큰 항목을 근거로 설명하고, 같은 직무·같은 수준에서 성향 거리가 가까운 인재상의 공고를 추천(옆으로 이동, 하향 아님).
4. 고용24 직업심리검사(직업선호도·직업가치관) 결과 연동은 확장 계획.

## 9. 트랙 A — 사다리 단계

| 단계 | 정의 | 분류 조건(초기값) |
|---|---|---|
| 목표 공고 | 최종 목표. 격차를 보여주기 위해 표시 | 직종 = 목표 직종 |
| ② 경력 발판 | 1~2년 뒤 목표 직종으로 이직 시 관련 경력으로 인정될 곳 | C ≥ 70 & 신입/경력무관 & F ≥ 60 |
| ③ 역량 키우기 | 경력 인정까진 아니어도 필요 역량 일부를 기를 곳(인턴·계약직·일경험 포함) | T ≥ 50 & C < 70 & F ≥ 60 |
| ① 즉시 적합 | 지금 역량으로 합격 가능성이 가장 높은 곳 | F ≥ 80 (위 단계에 해당 안 되는 공고) |

- 한 공고는 우선순위(목표 → ② → ③ → ①)에 따라 한 단계에만 배정.
- 단계별 3~5개 공고 + 전체 중 **지금 지원 1순위** 1개.

## 10. 트랙 B — 방향 전환

| 유형 | 제시 내용 |
|---|---|
| B1 서류 표현형 | 공고 요구 역량 대비 서류에서 드러나지 않은 경험 짚기, 경험을 역량 언어로 바꾼 문장 예시, 같은 수준 공고 재추천 |
| B2 조직 적합형 | 성향–인재상 차이 설명, 성향이 맞는 회사 공고 3곳, 성향을 강점으로 바꾸는 자기소개 예문, 자주 막히는 면접 질문과 답변 구조, 고용센터 모의면접 연결 |

## 11. 추천 카드 구조

| 구역 | 내용 |
|---|---|
| **A. 한마디** | 공감 + 핵심 1~2문장 |
| **B. 왜 이렇게 판단했나요?** | 근거 3가지(지금의 나 / 목표까지 거리 / 이 공고가 채워주는 것). 사실 → 해석 → 제안 순서, 근거마다 출처 표시 |
| **C. 이후 계획** | 지원 전 → 입사 후 1~3개월 → 4~6개월 → 7~12개월 → 12개월 이후, 플랜 B |

### 예시 1 — 자격 격차형(서류 5회 탈락, 목표 기계설계, 추천 C사 품질관리)

> 수치는 예시값

- **A.** 다섯 번의 도전 끝에 찾은 우회로예요. 돌아가는 길 같지만, 설계직에 가장 빨리 닿는 길일 수 있어요.
- **B.**
  1. 지원하신 5곳 중 4곳이 '관련 경력 1년 이상'을 우대했어요. 실력보다 경력 항목이 비어 있던 게 가장 큰 차이였던 것 같아요. *(내 지원 이력 분석)*
  2. 기계설계에 필요한 역량 중 지금 갖춘 건 약 45%예요. 특히 도면 해독·공정 이해 경험이 비어 있어요. *(직업정보 역량 비교)*
  3. 이 공고는 매일 도면을 보고 공정을 점검하는 일이라 1년이면 약 70%까지 오를 것으로 예상돼요. 신입 채용도 활발한 직무예요. *(공고 분석, EIS 구인배수)*
- **C.**

  | 시점 | 할 일 |
  |---|---|
  | 지원 전(D-5) | 이력서에 CAD 수업 프로젝트를 '도면 작성 경험'으로 기재 |
  | 입사 후 1~3개월 | 담당 제품 도면·검사 기준 익히기, 매주 업무 기록 한 줄(→ 경력기술서) |
  | 4~6개월 | 내일배움카드 3D CAD 과정 병행 |
  | 7~12개월 | 역량 충족도 재점검, 70% 이상이면 ②단계(설계 보조) 공고 알림 |
  | 12개월 이후 | 목표 공고 재도전 |
  | 플랜 B | D사 설비보전 공고 |

### 예시 2 — 조직 적합형(요건 충족도 평균 90%, 면접 4회 탈락)

- **A.** 자격은 이미 충분해요. 부족한 게 아니라, 지금까지 지원한 회사들과 일하는 방식이 조금 달랐을 수 있어요.
- **B.**
  1. 5곳의 요건 충족도는 평균 90%, 서류는 4번 통과했지만 면접은 모두 아쉬웠어요.
  2. 4곳의 인재상이 공통으로 '도전·빠른 실행'을 강조했어요. 자가진단의 신중하고 꼼꼼한 성향과는 결이 달랐을 수 있어요.
  3. 기업이 탈락 사유를 알려주지 않기 때문에 이건 가능성이에요. 맞는지 한번 돌아봐 주세요.
- **C.** 정확성·품질·체계를 중시하는 회사 공고 3곳 / 신중함을 '리스크를 미리 잡아내는 역량'으로 표현한 자기소개 예문 / 면접 답변 구조 + 모의면접 연결 / 2주 내 3곳 지원 → 결과 입력 → 재진단

## 12. 말투·윤리 원칙

1. **금지 표현**: "눈을 낮추세요", "하향 지원", "현실적으로", 탈락 사실 부각
   **사용 표현**: "우회로", "발판", "경력 한 줄", "궁합"
2. **결함이 아니라 궁합**: 성향은 "문제"가 아니라 "회사와의 궁합"으로 설명
3. **가설로 제시**: 탈락 원인은 추정임을 밝히고 사용자에게 확인 질문
4. **약속 금지**: "합격 보장", "경력 인정됨" 대신 "가능성이 높아요"
5. **선택권 존중**: "목표 공고만 보기" 옵션, 👍/👎 피드백으로 말투 조정
6. **개인정보**: 성향·지원 이력은 기본 비저장, 저장 시 동의

## 13. AI와 규칙의 역할 분담 (환각 방지)

| 규칙·데이터로 계산 | 생성형 AI가 담당 |
|---|---|
| F·T·C·S 점수, 역량 충족도 %, 진단 분기, 단계 분류 | 경력 서술 → 역량 구조화 |
| 구인배수·마감일 등 모든 수치 | 공고 본문 → 요구 역량·인재상 추출 |
| 계획표의 시점 틀, 훈련과정 매칭(API) | 탈락 패턴 해석 문장, 설득 한마디, 근거 설명, 계획 문장 개인화, 자기소개 예문 |

- 수치는 템플릿 슬롯에만 삽입하고 AI는 수치를 새로 만들지 않는다.

| | 훈련과정 추천(부족 역량별, 취업률·만족도순) | 국민내일배움카드 훈련과정 |
| | 마이페이지(지원 현황 보드 · 결과 입력 · 재진단 기록 · 알림), 커리어 경로 타임라인 | 모의데이터, 계산값 |

| | 상담사 대시보드(반복 탈락자 목록 · 진단 요약 · 상담 요청) | 모의데이터 |
